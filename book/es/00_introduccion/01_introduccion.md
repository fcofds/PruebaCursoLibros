El Inspector contiene información descriptiva del elemento seleccionado de alguna de las vistas.

Las herramientas de interacción con los elementos de la escena están situadas en la barra de herramientas y son las típicas de mover, rotar y escalar. Se pueden seleccionar con los aceleradores de teclado Q, W, E, R siendo la Q para mover la escena W, E, R para mover, girar y escalar el objeto seleccionado. Es lo mismo que se tienen por ejemplo para maya, estas acciones quedan reflejadas en las herramientas de edición.
Para mover la escena se realiza de forma similar a maya. Las acciones básicas son:
•	Mover hacia los lados la escena. Botón central del ratón o botón izquierdo con la opción q activada.
•	Rotar escena: tecla ALT + botón principal del ratón.
•	Zoom: rueda del ratón o ALT + botón derecho.
•	Mirar hacia un lado: botón secundario del ratón para modificar la visualización.
