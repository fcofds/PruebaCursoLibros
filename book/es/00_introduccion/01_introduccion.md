# 1. Introducción

La interfaz de Unity es la que se puede ver en la Figura 1. En project se tiene el repositorio de elementos que se pueden incorporar a la escena. Hierarchy almacena los elementos que se van incorporando a la escena. Escena contiene el editor que permite visualizar y modificar la escena. El Inspector contiene información descriptiva del elemento seleccionado de alguna de las vistas.
